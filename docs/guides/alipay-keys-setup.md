## 1. 先搞清楚三种密钥

| 名称 | 谁生成 | 用途 | 是否填入 HuaJian_Pay |
| --- | --- | --- | --- |
| **应用私钥** | 你本地生成 | 请求支付宝接口时签名 | **要填** |
| **应用公钥** | 由应用私钥导出 | 上传给支付宝开放平台 | **不要填** |
| **支付宝公钥** | 支付宝开放平台返回 | 校验支付宝异步通知 | **要填** |

最常见错误：

1. 把 **应用公钥** 误填到 **支付宝公钥**
2. 把 **支付宝公钥** 误填到 **应用私钥**
3. 只复制了密钥中间内容，丢失 `BEGIN/END` 或截断内容

---

## 2. 正确获取顺序

1. 登录 [支付宝开放平台](https://open.alipay.com/)
2. 进入控制台，创建或打开应用，拿到 **APPID**
3. 使用开放平台密钥工具或 OpenSSL 生成 **RSA2** 密钥对
4. 得到：
   - 应用私钥
   - 应用公钥
5. 在开放平台 **接口加签方式** 中选择 **RSA2（SHA256WithRSA）**
6. 上传 **应用公钥**
7. 复制开放平台返回的 **支付宝公钥**
8. 回到 HuaJian_Pay Admin → 支付宝通道：
   - App ID = APPID
   - 应用私钥 = 你的应用私钥
   - 支付宝公钥 = 开放平台返回的支付宝公钥
9. 保存

---

## 3. 如何生成密钥

### 方式 A：支付宝开放平台密钥工具（推荐）

1. 打开开放平台文档中心或控制台中的密钥工具下载入口
2. 下载 **支付宝开放平台密钥工具**
3. 选择：
   - 密钥格式：RSA2
   - 密钥长度：2048
4. 生成后会得到：
   - 应用私钥
   - 应用公钥
5. **应用私钥只保存在你自己的安全位置**，不要发到聊天、截图、Git

### 方式 B：OpenSSL（适合熟悉命令行）

```bash
openssl genrsa -out app_private_key.pem 2048
openssl rsa -in app_private_key.pem -pubout -out app_public_key.pem
```

- `app_private_key.pem` → 填到 HuaJian_Pay 的 **应用私钥**
- `app_public_key.pem` → 上传到支付宝开放平台
- 支付宝返回的公钥 → 填到 HuaJian_Pay 的 **支付宝公钥**

## 4. 如何获取支付宝公钥

1. 打开 [支付宝开放平台控制台](https://open.alipay.com/develop/manage)
2. 进入你的应用
3. 找到 **开发设置 / 接口加签方式**
4. 选择 **公钥** 模式，算法选 **RSA2**
5. 粘贴并保存 **应用公钥**
6. 保存成功后，页面会显示 **支付宝公钥**
7. 复制完整支付宝公钥

注意：

- **支付宝公钥 ≠ 应用公钥**
- 支付宝公钥是平台给你的，不是你本地生成的那把公钥

---

## 5. 如何填入 HuaJian_Pay

进入：

```text
Admin → 支付宝通道
```

填写：

| 字段 | 填什么 |
| --- | --- |
| App ID | 开放平台应用 APPID |
| 应用私钥 | 本地生成的应用私钥完整内容 |
| 支付宝公钥 | 开放平台返回的支付宝公钥完整内容 |
| 异步通知 URL | 通常 `https://你的域名/channels/alipay/notify` |
| 同步跳转 URL | 可选 |

保存规则：

- 密钥输入框留空 = 保留原值
- 填写非空 = 替换原值
- 保存成功后，输入框会重新变空，这是正常的（系统不回显完整密钥）

---

## 6. 报错对照

### `应用私钥未配置，请填写完整私钥`

可能原因：

- 应用私钥为空
- 只粘贴了部分内容
- 误把公钥粘贴到了私钥框
- 复制时截断了 `BEGIN/END` 或中间字符

处理：

1. 重新打开私钥文件
2. 全选复制完整内容
3. 粘贴到 **应用私钥**
4. 保存

### `支付宝公钥未配置，请填写完整公钥`

可能原因：

- 支付宝公钥为空
- 误填了应用公钥
- 只填了 APPID
- 内容不完整

处理：

1. 回到开放平台加签配置页
2. 复制 **支付宝公钥**
3. 粘贴到 **支付宝公钥**
4. 保存

---

## 7. 安全要求

- 真实私钥/公钥 **禁止** 写入文档、聊天、Git
- 本教程只使用脱敏示意
- 生产环境优先通过安全配置注入密钥
- 泄露应用私钥等于别人可以冒充你的应用发请求

---

## 8. 验收标准

保存成功后应满足：

1. 不再提示“应用私钥未配置 / 支付宝公钥未配置”
2. Admin 显示密钥已配置状态（不回显原文）
3. 可发起真实小额支付
4. 支付宝回调可被 RSA2 验签通过
